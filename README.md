# CareerTwin AI

Interactive UI prototype for CareerTwin AI — a dynamic, AI-powered "digital twin" of a professional identity that replaces the static résumé.

## Contents
- `index.html` / `careertwin-mockups.html` — self-contained interactive mockup (6 screens, Professional/Recruiter roles). Open in any browser.
- `careertwin-design-spec.md` — written design specification of every screen, component, and user flow.

## Screens
Dashboard · Skill analysis · Ask your twin (chat) · Sources & setup · Recruiter discovery · Candidate view

Built as a front-end design prototype (HTML/CSS/JS, Chart.js, Tabler icons).
